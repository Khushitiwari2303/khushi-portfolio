# Khushi Tiwari - Personal Portfolio

A small, responsive personal portfolio website built with HTML, CSS and JavaScript.

## Features

- Responsive design
- Personal profile section
- Skills
- Projects
- Experience
- Certifications
- Contact section
- LinkedIn and GitHub links
- Mobile navigation
- Personal profile photo

## Tech Stack

- HTML5
- CSS3
- JavaScript

## Run locally

1. Clone the repository.
2. Open the folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.

## Before publishing

Update:
- Email address in `index.html`
- GitHub profile URL
- Project links when your repositories are ready
- Experience/company details if needed
